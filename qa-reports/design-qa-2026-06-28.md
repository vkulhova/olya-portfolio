## Рекомендації (за пріоритетом)

1. 🔴 **Замінити `illustration-contact.png`** — поточний файл є порожнім. Оля має надати реальну ілюстрацію (ноутбук з тюльпаном із Figma) і замінити файл у `public/images/illustration-contact.png`.

2. 🟡 **Підключити Formspree** — замінити `YOUR_FORM_ID` у [`components/Contact.tsx:17`](../components/Contact.tsx) на реальний ID з formspree.io. Оля казала що вже підключала пошту — потрібно уточнити endpoint.

3. 🟡 **Фон Contact** — у Figma фізична фото-текстура зім'ятого паперу. Якщо хочеться точно відтворити — розмістити `crumpled-paper.jpg` в `public/images/` і додати як `background-image`. Поточний CSS noise — прийнятне наближення.

4. ⚪ **Активний стан nav** — зараз «PORTFOLIO» статично золотий. Можна додати IntersectionObserver щоб активний пункт підсвічувався при скролі — але це не критично.

5. 🚀 **Після виправлень** — `npm run build` і деплой через Vercel (`vercel --prod`).

## Не вдалося перевірити

- **Hover-стани** (nav links, кнопка «Post it!», іконки) — preview не підтримує hover через CSS; стани описані в коді як `hover:` утиліти, але не перевірені візуально.
- **Мобільна адаптивність (375px / 768px)** — не перевірялася в цьому раунді; компоненти мають `sm:` breakpoints у Tailwind.
- **Tablet (768px)** — аналогічно.
- **Figma скріншоти у високій роздільності** — Figma MCP Starter plan rate limit не дозволив отримати свіжі скріншоти; використано референси з попередньої сесії.
- **`illustration-desk.png`** — файл відображається (`object-contain`, 465px висота), але не вдалося перевірити чи це реальна ілюстрація Олі, а не плейсхолдер.
